# 窗口即图块

应用 `design` 和 `design-system` 的字体、颜色与层次规范。Consolas，深墨蓝背景，青绿表示信号，珊瑚红表示爱与冲突。三层色彩在 `assets/design-tokens.json` 统一定义。

核心约束是让窗口位置有含义。每个图块是独立真实控制台；组合后的桌面轮廓必须在不阅读窗口内容时也能识别。完整心形、缺失心形、分裂心形、圆到直线、正弦到直流、无穷双环、护盾、牢笼、数字与身份字母均由确定的坐标模板生成。保持队形时不做漂移、随机抖动或呼吸缩放。

18 个进程中，16 个为可显示／隐藏的图块演员，2 个为固定的歌词与节奏阅读区。字句触发重排；重拍主要通过内部扫描、字符冲击与明暗表达。其他叙事段落切回中央画面与六个辅助终端，释放内部图形的细节空间。

参考用户给出的 [world.execute-me-ascii](https://github.com/yym8224961/world.execute-me-ascii) 的语义动作和独立字幕阅读区。Windows 进程、几何编排与绘制代码在本工程独立实现；参考歌词仅缓存到本地，并按用户音频起音校正。没有把参考仓库的场景源码打包进本项目。

逐词边界仍是估计，不将其描述为逐字人工校准。瞬态与拍点文件可检查；缺失拍点被显式标记为预测。音频设备位置是共享时钟。
