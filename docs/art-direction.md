# 终端芭蕾 / world.execute(me);

按 `design` 与 `design-system` 技能建立：primitive → semantic → component 三层色彩。Consolas 单一等宽字体；深墨蓝背景，青绿代表联结，冷白代表结构，珊瑚红代表冲突，暖金代表生命。真实系统窗口边框保留。

七个窗口是同一台机器的七个器官：中央主舞台，两侧分别呈现信号、几何、粒子、记忆、频谱和状态。图形由每帧程序计算，避免日志替代画面。字符画通过 Win32 整帧缓冲绘制，目标 24 FPS；窗口仅在场景过渡与少量节拍呼吸时运动。

叙事由供电与构建开始，经过数学形态、生命与身份变换，再进入孤立、碎片与递归冲突，最后以心形方程和囚笼收束。32 个语义场景，7 种窗口构图；节拍改变线框尺度、粒子散射和大字亮度；真实频谱驱动各窗的 16 频段图形。避免高频整屏反白。

歌曲使用用户提供的本地文件，解码缓存和音频不提交仓库。音频设备播放位置是主时钟，不依赖七个窗口各自开始运行的时间。歌词参考时间来自 [LRCLIB 记录 1039162](https://lrclib.net/api/get/1039162)，仅保存语义编排，不嵌入整首歌词。参考时间未经逐字人工对齐，支持播放偏移与进度跳转。
